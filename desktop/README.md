# FAC Desktop Edition

The Desktop edition provides the guided browser interface for FAC.

Keep this entire folder together. Run the installer from inside this
folder; do not move the installer out by itself.

The installer:

1. asks where FAC should be installed;
2. copies the complete application;
3. creates a private `.venv`;
4. installs the Python requirements;
5. creates `.env` only when one does not already exist; and
6. starts FAC locally.

Mac:

```text
Install FAC - Job Tracker.command
```

Windows:

```text
Install FAC - Job Tracker.bat
```

Read `README_START_HERE.txt` for installation details and
`FAC_SEARCH_TIPS.txt` for resume and search-configuration guidance.
