# Publishing a FAC Release

The Core and Desktop editions use the same project version.

Current version:

```text
1.9.0
```

Recommended release downloads:

```text
FAC-Job-Tracker-Core-v1.9.0.zip
FAC-Job-Tracker-Desktop-v1.9.0.zip
```

Create one GitHub release titled:

```text
FAC - Job Tracker v1.9.0
```

Attach both ZIP files to that release.

Before publishing, confirm that no `.env`, API key, résumé, output folder,
cache, or personal job-search history is included.
